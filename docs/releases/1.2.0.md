SnowPatcher now detects Epic Games installations. Copies from other stores and manual installations can be selected with Browse, without Steam or Epic receipts.

- Resolves content folders automatically and shows the installed version when available.
- Supports compatibility checks, backups, restore and change monitoring across these installations.
- Keeps compatible manual edits. Unknown changes to managed files still need review; missing launcher data is never treated as proof of original files.
- Fixes folder detection, stale installation records and a race that could display outdated build information.

**Installation and updates**

Use the Windows setup EXE, or extract the portable Windows ZIP and run SnowPatcher.exe. Version 1.1.0 can update from the app; version 1.0.0 needs one manual installation. Mods, backups and preferences are kept.

**Validation**

Steam, Epic-layout and manual-installation checks passed, including backup, restore and reapplication. Epic support was checked with local installation fixtures and real Epic manifest files; an in-game test on an Epic copy of SnowRunner is still pending. The Linux build is provided without an in-game test.
