SnowPatcher now supports XML attribute patches, so mods can change individual game settings without replacing entire XML files.

- Combines compatible edits to different attributes in the same resource. Conflicting changes are reported before Apply writes game files.
- Checks each edited attribute's expected value and preserves unrelated XML content.
- Adds XML edits to the package format and authoring tools. Packages using them require SnowPatcher 1.3.0 or newer.
- Prevents compatibility checks, backups, Apply and Restore from competing for access to game files.

**Installation and updates**

Use the Windows setup EXE, or extract the portable Windows ZIP and run SnowPatcher.exe. Existing users can update from the app; version 1.0.0 needs one manual installation. Mods, backups and preferences are kept.
