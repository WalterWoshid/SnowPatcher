SnowPatcher can now combine compatible script extensions with edits from other mods. Nearby Repair and Repair Transfer 1.0.5 use this support to share the truck Functions menu.

- Preserves existing script instructions when a mod adds functions, members or instructions.
- Checks required game code, member names and insertion points before combining patches. Conflicting changes stop Apply before game files are written.
- Adds array operations and named references to the authoring tools, with compatibility checks generated during packaging.

**Installation and updates**

Use the Windows setup EXE, or extract the portable Windows ZIP and run SnowPatcher.exe. Existing users can update from the app; version 1.0.0 needs one manual installation. Mods, backups and preferences are kept.

Nearby Repair 1.0.0 and Repair Transfer 1.0.5 require SnowPatcher 1.4.0 or newer. Update older Repair Transfer installations before enabling Nearby Repair.

**Validation**

Build, formatting, patch composition, conflict and rollback checks passed. All six current mods were checked together, including disabling either repair mod and preserving the other. Nearby Repair and Repair Transfer were confirmed working in-game on Windows Steam build 26218478. The Linux build is provided without an in-game test.
